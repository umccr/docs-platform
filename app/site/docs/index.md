# UMCCR documentation

Documentation published by UMCCR teams. Each site is written and reviewed in its own repository and published
here when it changes.

<div id="umccr-catalogue"></div>

## Publishing your documentation

Any UMCCR repository can publish a site at `https://docs.umccr.org/<name>/`. The source stays in your repository;
this platform provides the build, the theme, sign-in and hosting.

- [Onboarding a repository](onboarding.md): add a configuration file and register the site.
- [Authoring](authoring.md): what you can write, including Obsidian vaults.
- [Publishing contract](publishing.md): what the platform guarantees and enforces.
